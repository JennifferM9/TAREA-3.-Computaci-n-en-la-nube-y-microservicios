# Tarea 3: Computación en la Nube y Microservicios

Página web básica desarrollada con HTML y CSS que explica qué es la computación en la nube y los microservicios. Fue desplegada en la nube desde un repositorio público de GitHub como práctica de despliegue continuo.

## Sitio en vivo

Ver sitio publicado: https://tarea3-computacion-en-la-nube.netlify.app

## Tecnologías utilizadas

- HTML5
- CSS3
- Git y GitHub (control de versiones)
- Netlify (despliegue en la nube)

## Estructura del proyecto

- `index.html`: estructura y contenido de la página
- `style.css`: estilos y diseño
- `README.md`: documentación del proyecto

## Despliegue

El código se encuentra en este repositorio público de GitHub, que está conectado con Netlify. Cada vez que se sube un cambio al repositorio, el servicio lo detecta y publica automáticamente la nueva versión del sitio (despliegue continuo).
