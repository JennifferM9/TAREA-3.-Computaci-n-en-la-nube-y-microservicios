Computación en la Nube y Microservicios

Tópicos especiales y avanzados

¿Qué es la computación en la nube?

Es el uso de servidores remotos conectados a Internet para almacenar, administrar y procesar datos y programa.

  • IaaS: Alquila componentes básicos como servidores virtuales, redes y almacenamiento. Un ejemplo común es Amazon Web Services (AWS).
  • PaaS: Ofrece un entorno de desarrollo para crear, probar y administrar aplicaciones sin preocuparse por el hardware. Un ejemplo es Google App Engine.
  • SaaS: Entrega aplicaciones listas para usar a través de un navegador web. Un ejemplo es Google Workspace (Gmail, Drive).

¿Qué son los microservicios?

Son un estilo de arquitectura de software en el que una aplicación grande se divide en pequeños servicios independientes. Cada servicio cumple una función específica, maneja su propia base de datos y se comunica con los demás mediante interfaces web o APIs.

Ventajas

  • Escalabilidad independiente: Permite ampliar los recursos únicamente del servicio que lo necesita.
  • Aislamiento de fallos: Si un microservicio falla o se cae, el error se contiene en esa parte y los demás servicios continúan funcionando con normalidad.
  • Libertad tecnológica: Cada servicio puede desarrollarse con diferentes lenguajes de programación, frameworks o bases de datos según lo que mejor convenga a su tarea específica.
  • Agilidad y despliegue rápido:Facilita que equipos pequeños y especializados trabajen de manera autónoma en diferentes servicios y lancen actualizaciones con mayor frecuencia.

¿Cómo se desplegó este sitio?

Usé el servicio de Netlify ya que es gratuito y se conecta directo con GitHub.

  1. El código se almacena en un repositorio público de GitHub.
  2. Se vincula la cuenta de GitHub con Netlify.
  3. Se selecciona el repositorio y Netlify toma los archivos de ahí.
  4. Cada vez que se hace un commit y se sube a GitHub, Netlify detecta el cambio y republica el sitio automáticamente.
